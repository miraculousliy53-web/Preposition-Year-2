# 🐾 Animal House Obby: Preposition Quest 🐾

An interactive 3D browser learning game created using **Three.js**, designed specifically for **Malaysian Year 2 English pupils** to master spatial prepositions (**ON**, **IN**, **UNDER**).

🎮 **[Click Here to Play the Live Game](https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/)**

---

## 🌟 Key Features

* **3D Roblox-Style House Environment:** Explorable rooms including Living Room, Bedroom, Kitchen, Bathroom, and Dining Room.
* **Interactive Preposition Missions:** 20 target grammar challenges with active visual cues (green glowing rings & direction arrow for active tasks; yellow rings for completed ones).
* **Curriculum-Aligned Grammar Focus:** Focuses on standard Year 2 sentence patterns:
  * *Singular:* `There is a/an [animal] [preposition] the [object].`
  * *Plural:* `There are [number] [animals] [preposition] the [object].`
* **Cross-Platform Controls:**
  * **Desktop:** `WASD` / Arrow keys + `Spacebar` to jump + Mouse camera drag.
  * **Mobile / Tablet:** Touchscreen Virtual Joystick + On-screen Jump Button.
* **Audio & Visual Rewards:** Built-in Web Audio API sound effects, score tracking, countdown timer, room unlocks, and celebration fireworks.

---

## 🎮 How to Play

1. **Enter Your Name:** Type your name on the title screen to begin.
2. **Find Animals:** Follow the green beacon light or directional arrow on top to find glowing mission circles.
3. **Build Sentences:** Step into a green ring to start a mission. Tap or drag the scrambled word tiles in order to form the correct sentence describing the 3D animal scene.
4. **Earn Points & Unlock:** Get 100 points per correct answer and clear all 20 missions to finish the obby!

---

## 🛠️ Technical Details

* **Single-File Architecture:** Built as a standalone `index.html` file containing HTML5, CSS3, and JavaScript.
* **Graphics Engine:** [Three.js](https://threejs.org/) (WebGL 3D rendering).
* **Audio Engine:** HTML5 Web Audio API (procedural sound generation without external audio file dependencies).
* **Deployment:** Hosted directly via GitHub Pages.
